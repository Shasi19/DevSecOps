# Visual guide library

The 28 product guides each include ten original, topic-specific study cards in SVG and PNG. Cards cover a system map, workflow, security, delivery, observability, diagnosis, recovery, resilience, a production scenario, and rapid revision. The visuals are newly authored and do not reproduce the inaccessible LinkedIn reference image.

Regenerate the cards on macOS with Python 3 and Pillow installed: `python3 notes/visuals/generate.py`. The script uses `sips` for SVG rendering.

# Guide index

These folders contain original study guides corresponding to the 27 items shown on the linked package page, plus OCI. Start with the relevant guide's `README.md`; each includes a topic roadmap, concepts, examples, an original Mermaid architecture/workflow diagram, troubleshooting, a production scenario, and quick revision points. GitHub renders Mermaid diagrams; no paid-handbook images or text are reproduced.

The linked page provides product descriptions, not the paid handbook contents or tables of contents. The guides are broad, independent learning material and cannot be claimed to cover the unseen books' exact topic lists. No handbook text or proprietary examples have been reproduced here.
